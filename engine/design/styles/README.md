# Named ad styles

- [Style 1](style-1/README.md): approved condensed typography and joined highlights.
- [Style 2](style-2/README.md): approved Classic visual match with −1% tracking.
- [Style 3 — Coral highlights](style-3/README.md): approved Roboto Bold with coral/black/pink joined highlights.

All four styles are saved production presets in the shared composition. Styles 3/4 were approved and corrected on 2026-10-03; both use the same 28% black overlay beneath all content as Styles 1/2. New copy uses measured compact placement centered above the canvas midpoint. Original references, background cleanup prompts, editable layer maps, direct approved Paper snapshots and checked renderer previews are archived in each style folder. Style 4 loads the exact locally installed Times New Roman font, with no silent substitution; its OS font file is not bundled.
